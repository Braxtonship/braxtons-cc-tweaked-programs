## introduction
this is a repo for the **CC:Tweaked** mod for **Minecraft**.
i recommend using the **[BACPAX package manager](https://github.com/Braxtonship/braxtons-cc-tweaked-programs/blob/main/BAC-package-manager.lua)** for all packages here *(as well as packages by others)*.
install **[BACPAX PM](https://github.com/Braxtonship/braxtons-cc-tweaked-programs/blob/main/BAC-package-manager.lua)** here *(using **wget**)*

    wget "https://raw.githubusercontent.com/Braxtonship/braxtons-cc-tweaked-programs/refs/heads/main/BAC-package-manager.lua" bacpax
